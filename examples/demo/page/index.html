Watch a stop hook send broken code back

When a coding agent ends its turn, stop-rules cuts what it changed into pieces and asks a judge one yes or no question per piece and rule. A score of 0.6 or more means the rule is broken, and that piece goes back to the agent to fix before you see it. Here two judges run the same check at the same moment, Jev and GPT-6 Luna, each with its own measured speed, cost and catch rate.
