stop-rules team server

This is a locked down proxy for Jev and the OpenAI judge. It holds the API keys so that nobody on the team has to, and it answers three routes:

  • GET /health, which says whether the server is configured
  • POST /v1/systemone, Jev, which needs the team token
  • POST /v1/responses, the OpenAI judge, which needs the team token

Point a repository at it with stop-rules team <this url>. Source and setup notes: github.com/haystackeditor/stop-rules.
